Chưa chạy cập nhật DATA Tổng.

Import Danh sách nhân sự (PGs OPPO)

Dùng đúng form cột: Staff ID, Staff Name, Code, Email, Title, Area, Province, District, Shop ID, Shop, Channel, Big Channel, Joined at, Released at, Loại gán shop, Là Shop chính, trainer, sao, THÂM NIÊN THÁNG, LOẠI THÂM NIÊN, TRẠNG THÁI, Size shop, SALE. Trạng thái là trường cố định — sau khi đã fix cho 1 PG, import các lần sau KHÔNG ghi đè Trạng thái của PG đó nữa (dù cột TRẠNG THÁI trong file ghi khác), chỉ cập nhật các trường khác (Shop, Trainer, Sale, Sao...). Cột TRẠNG THÁI trong file chỉ áp dụng cho PG hoàn toàn mới (mã Code chưa từng có trong hệ thống) — nhận: OFF, THAI SẢN, TẠM OFF, CODE ĐẠI LÝ (để trống = Đang làm). Muốn đổi Trạng thái của PG đã có, dùng đúng dropdown Trạng thái tại bảng Danh sách PGs (Tổng quan ▸ Nhân sự).

Hoặc ghép từ 2 file HRM rời (không cần đúng mẫu chuẩn ở trên): Danh sách gán Shop PG (Staff ID, Staff Name, Code, Title, Loại gán shop, Area, Province, District, Shop, Channel, Joined at, Là Shop chính...) và Sao PGs (Mã NV, Ngày vào làm, Hạng sao hiện tại). Hệ thống ghép CHÍNH XÁC Mã NV (Sao PGs) ↔ Code (DS gán Shop PG), chỉ lấy đúng dòng "Loại gán shop" = "PG" (không dùng cột Title vì có nhiều biến thể) và dòng Shop chính. Cột Ngày vào làm lấy theo file Sao PGs (ưu tiên hơn file gán Shop). Sau khi import 2 file, xem trước danh sách bên dưới rồi bấm "Cập nhật Nhân sự" mới thật sự ghi vào Tổng quan ▸ Nhân sự.

Import danh sách On/Off nhân sự

Dùng đúng file export nhân sự HRM gồm 2 sheet tên "on" và "off" (42 cột đầy đủ). Hệ thống chỉ đọc các cột cần thiết: Code, Full name, Area, Joined at, Off date, Status. Lần import đầu tiên nên gồm đủ dữ liệu lũy kế các tháng trước; các lần sau chỉ cần nộp danh sách On/Off từ đầu tháng đang xem tới thời điểm import.

Import dữ liệu Nhân sự các hãng (theo Shop)

Dùng file HR tổng hợp theo Shop (cột: Store ID, Store name, Province, Miền, Channel, Shop Focus, SL PG SAMSUNG/XIAOMI/VIVO/REALME/HONOR/KHÁC + Thâm niên từng PG...). Riêng số liệu PGs OPPO KHÔNG lấy từ file này — luôn tham chiếu đúng data Nhân sự (Danh sách PGs) đã import, file này chỉ bổ sung số liệu các hãng đối thủ.

Riêng Import Target FTF theo từng chiến dịch cần chọn đúng chiến dịch trước — vẫn nằm ở Cài đặt ▸ Target (chọn chiến dịch Loại "FTF").

Import kết quả Truyền thông

Import Truyền thông cần chọn đúng chiến dịch (Nội bộ/Đối tác) đang muốn đổ dữ liệu, nên vẫn nằm ở đúng chỗ: Tiến độ KPI ▸ Truyền thông (chọn Loại rồi import ngay dưới thẻ tổng). Mục này chỉ là lối tắt.

Import dữ liệu S.O tháng trước

Dùng file xuất Sellout theo dòng (mỗi dòng = 1 lượt bán): Store ID, Store name, Staff code, Staff name, Area, Vùng, Title, Sellout date, Channel, Model, Category (Phone/IOT/Accessories), Color, Sellout. Hệ thống tự gộp theo từng PG (Staff code) — ra số lượng bán theo 3 danh mục và chi tiết theo từng Model.

Tài khoản

Thông tin đăng nhập của bạn và (nếu là Admin) quản lý tài khoản Trainer.

Đổi mật khẩu

Tạo tài khoản Trainer (chỉ Admin)

Trainer nhập sai mật khẩu đủ 5 lần sẽ tự khóa. Admin có thể mở khóa hoặc reset mật khẩu về 123456 trong danh sách bên dưới.

Sao lưu dữ liệu

Tải xuống toàn bộ dữ liệu hiện có (Trainer/Khu vực, PGs, Records, Coaching, Khảo sát, FTF, Truyền thông...) thành 1 file JSON để lưu trữ hoặc phục hồi khi cần.

Khôi phục dữ liệu — dùng khi chuyển sang máy/địa chỉ web khác (dữ liệu hiện lưu ngay trên trình duyệt của bạn, không tự chuyển theo). Chọn đúng file JSON đã export ở trên, hệ thống sẽ nạp lại toàn bộ dữ liệu — ghi đè hoàn toàn dữ liệu hiện có trên máy/trình duyệt đang mở.

Yêu cầu thay đổi trạng thái PG chờ Admin duyệt
Chỉ sau khi Admin bấm Duyệt thay đổi, trạng thái PG mới được áp dụng. PG có trạng thái khác Đang làm sẽ tự động bị loại khỏi các thống kê nhân sự/KPI dùng danh sách PG đang hoạt động.

🔗 Cập nhật dữ liệu từ Google Sheet
